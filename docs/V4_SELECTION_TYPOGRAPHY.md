# V4：选句密度与高可读排版

V4 针对真实成品中仍然出现的两个问题：

1. 一个条带塞入调查、背景、例子和结论，最终变成三行中文加三行英文；
2. 为了让一张卡“看起来丰富”，从演讲不同章节各抽一句，形成主题拼盘。

## 选句门槛

每个候选是一个原子观点，而不是字幕段落：

- 最多 28 个英文词、180 个源字符、两句话；
- 一般只承载一个命题，或一个两边都完整出现的对照；
- “观点 + 长例子”应拆成两个候选，由选句台决定用哪个；
- 每个候选提供 1–4 个可在原文或 claim signature 中核验的 `topic_terms`。

每个 ready pack：

- 4–5 条，不再默认凑 6 条；
- 按原视频时间升序；
- 相邻中心点最多相隔 120 秒，首尾最多跨 6 分钟；
- 用 1–3 个具体 `anchor_terms` 和一个 `focus_question` 定义边界；
- 每条都必须直接回答同一个 focus question；
- 一个主锚点至少连接除一条外的所有候选；
- 禁止把调查、升学、餐厅故事和 AI 因为都与“工作/学习”有关就拼成一张。

V3 选句通过后必须运行：

```bash
bin/qcard-promote work/<video-id>
```

该命令以 `selection_audit.json` 重建渲染器使用的 `angle_packs.json`，防止旧的
V2 主题清单绕过新的选句结果。

## 排版门槛

新任务默认：

```bash
bin/qcard-render-v4 work/<video-id> --mode all --style editorial
```

`editorial` 样式：

- 1440×1920、3:4；
- 4–5 个等高画面条；
- 中文优先系统 Semibold/Medium/Bold 字重；
- 中文 48px 以上、英文 30px 以上的硬下限；
- 每种语言最多两行；
- 文字放在画面下部渐变区，并使用黑色描边而不是大面积黑条遮挡人物；
- JPEG quality 96、4:4:4 (`subsampling=0`)；
- 中文自动清理模型常见的多余空格、数字与单位间空格和直角引号。

若文本无法在硬字号下容纳，渲染器报错并要求换更短的完整原句；不会继续缩成小字。

## 参考项目

设计审查参考了
[`chengyi-ai/native-subtitle-quote-image`](https://github.com/chengyi-ai/native-subtitle-quote-image)：
其 1440×1920 输出、五个时间点上限、源时间升序、精确取帧、4:4:4 JPEG 和逐张
视觉复核是有效的生产约束。本项目没有复制其“只保留烧录字幕”的产品边界，而是
继续绘制经过来源和翻译审计的中英双语文字。
